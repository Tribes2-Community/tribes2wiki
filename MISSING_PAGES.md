# Missing pages

The original tribes2wiki.com had **121 content pages** and
**87 uploaded files**. The Internet Archive captured
**75** of those pages and only **2** of the images, so a little under half the
wiki has to be rewritten by the community.

This file is generated by `npm run report-missing`. Don't edit it by hand -- write the
article instead, and it will drop off the list on the next run.
