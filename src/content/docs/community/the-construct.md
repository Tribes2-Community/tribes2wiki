**[The-Construct.net](https://www.the-construct.net)** is the home of the Tribes 2
**Construction Mod** — a long-running community built around building things in game rather
than fighting over them.

Construction turns Tribes 2 into something closer to a sandbox. Players place and assemble
structures across a map, and the community has kept at it for years: the site carries a
gallery of players' creations and has run building contests.

## Where to find them

| | |
| --- | --- |
| **Site and forums** | [the-construct.net](https://www.the-construct.net) · [forums](https://www.the-construct.net/forums/) |
| **Discord** | [discord.gg/jbxdbAm](https://discord.gg/jbxdbAm) |
| **IRC** | `#the_construct` on `irc.quakenet.org` |

The IRC channel is the older of the two chat homes and still listed by the site. If you are
not set up for IRC, the Discord is the easier way in.

## Playing there

You need Tribes 2 and a [community patch](/patches) first — see
[Tribes 2](/start/tribes-2) for the setup. The Construction Mod itself is a
[mod](/mods/mod), so it changes how the game plays compared to
[Base](/mods/base) or [Classic](/mods/classic).
