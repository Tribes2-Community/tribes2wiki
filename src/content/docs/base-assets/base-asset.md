A **base asset** is any stationary object on a [map](/scripting/map "Map") that belongs to one of the teams and provides that team with certain functions. In most [mods](/scripting/mod "Mod"), these are [base turrets](/base-assets/base-turret "Base turret"), [inventory stations](/equipment/inventory-station "Inventory station"), [vehicle pads](/equipment/vehicle-pad "Vehicle pad"), [generators](/base-assets/generator "Generator"), [solar panels](/equipment/solar-panel "Solar panel"), and [pulse sensors](/equipment/pulse-sensor "Pulse sensor"). All of these base assets are protected by shields when they are powered. These shields rely on the object's energy in order to protect the object. Generators and solar panels provide the power to other base assets. If a generator is damage to the point of being disabled, then it can no longer provide power to any base assets until it is repaired. Sometimes there are multiple generators that all power the same group of objects. In this case, every one of these generators needs to be destroyed in order for those base assets to lose power. If a base asset is not powered, it is completely inactive and its shields will not function.
