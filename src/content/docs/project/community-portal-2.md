## IRC

Tribes 2 used to have its own in-game chat that could only be reached by loading up Tribes 2, but after a while, almost every active player decided to use the much more robust irc.Dynamix.com IRC server instead. This server is what was used for Tribes 1 (and later, Tribes: Vengeance). However, this server eventually was taken down, and [irc.tribalwar.com](irc://irc.tribalwar.com) was put up to give the former denizens of Dynamix IRC a place to hang out. Once TribesNext RC3 comes out, you will be able to access all of these channels via Tribes 2 in-game IRC.

-   **General Tribes 2:** [#tribesnext @ irc.tribalwar.com](irc://irc.tribalwar.com/tribesnext)
-   **Competitive Players:** [#lastgasp @ irc.tribalwar.com](irc://irc.tribalwar.com/lastgasp)
-   **Goon Haven Server:** [#goonhaven @ irc.tribalwar.com](irc://irc.tribalwar.com/goonhaven)
-   **Tribes 2 Wiki:** [#tribes2wiki @ irc.tribalwar.com](irc://irc.tribalwar.com/tribes2wiki)

**Note:** irc.Arloria.net is no longer welcoming Tribes players. All Tribes channels on that server have migrated to irc.TribalWar.com, and we recommend you follow suit. RC2 of the TribesNext patch still directs in-game chat to Arloria, but RC3 will rectify this and point to irc.TribalWar.com instead. If you still have RC2, you should avoid the in-game chat.
