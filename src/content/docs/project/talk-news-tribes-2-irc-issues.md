## Connecting to the new IRC server

You will need an IRC client such as mIRC, X-Chat, Mibbit, etc. If you have a client installed, you should be able to click on this link to automatically launch that program and join the main channel: [TribesNext IRC](irc://irc.tribalwar.com/tribesnext)

To join other channels, such as the Goon Haven channel, the competition channel, or the Tribes 2 Wiki channel, type one of these commands into the chat window: /join #goonhaven /join #lastgasp /join #tribes2wiki
